A program that writes one line to `/output/entry.txt`: a one-star
review of Monday, written as though Monday were a restaurant.
Entered in make.fun's "One Star for Monday" bounty.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `/output/entry.txt` (132
characters, 22 words, one line, no trailing newline). Running it
again writes the exact same bytes.
